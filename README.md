# 2027 赛季征途 Uprising 视觉组考核

本项目面向视觉组考核（自瞄方向）的离线视频评测。基础任务是在考核视频中检测指定颜色的装甲板，标出四个角点和中心点，估计装甲板中心在相机坐标系下的三维位置，并在画面上显示检测结果和处理耗时。

## 环境与安装

考核环境为 Ubuntu 22.04，开发语言为 C++。

| 项目 | 当前说明 |
| --- | --- |
| C++ 编译器及语言标准 | 随源码补充编译器版本和 C++ 标准 |
| 构建与运行依赖 | 随源码补充依赖名称、版本和安装命令 |
| 模型文件 | 使用模型时补充权重来源、存放路径和获取方式 |

获取仓库：

```bash
git clone https://github.com/ZT-Visual-Group-Training/bingbingbing.git
cd bingbingbing
```

## 考核数据

将战队提供的两个 ZIP 放入本地 `data/`，分别解压。Ubuntu 上可以用以下命令保留压缩包内的目录结构：

```bash
unzip data/2026-11-13_18-28-12_830451.zip -d data/
unzip data/2026-11-13_18-25-25_462305.zip -d data/
```

| 两组数据包内的相对路径 | 内容 |
| --- | --- |
| `video/video.avi` | 原始考核视频 |
| `video/frames.csv` | 视频帧记录 |
| `calibration/intrinsics.yaml` | 相机内参与畸变参数 |
| `calibration/handeye.yaml` | 手眼标定数据 |
| `imu/frame_imu.csv` | 与视频帧对应的 IMU 数据 |
| `metadata.json` | 采集元数据 |

小装甲板尺寸为宽 **135 mm**、高 **56 mm**，高度取灯条长度。
